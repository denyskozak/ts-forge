## Новые функции пользователя

**Анализ проекта** запускается при выборе папки и перед каждой задачей. Он собирает пути, определения/номера строк, импорты и версии выбранных framework dependencies. Кэш обновляется по hash файлов. В запрос попадает ограниченная выборка по релевантности задаче. Карта хранится в локальном SQLite, в проект не записывается.

**Формат Auto** спрашивает локальную LLM, какой из трёх форматов ей удобнее, и кэширует ответ для endpoint/model name. При недоступности модели используется compact с объяснением. Модель выбирает представление; заявления об оптимальной токенизации или доказанной экономии нет. После замены весов под тем же именем используйте ручной формат, пока не реализована инвалидация preference по model digest.

**Test connection** использует несохранённые поля Settings: проверяет локальный адрес, доступные модели, отсутствие cloud-признаков, поддержку tools и короткую генерацию. Результат показывает время и понятную ошибку. Без имени модели выполняется только discovery. Подключение сейчас через Ollama HTTP; произвольный путь к GGUF не поддерживается.

## Проверки

31/31 автоматических тестов проходят; typecheck, production build и нативный Electron smoke проходят. Тот же smoke прошёл внутри упакованного `release/v0.2/mac-arm64/Forge.app`, включая worker и компилятор. Найденная при упаковке потеря TypeScript declaration files исправлена: compiler resources включены отдельно от ASAR. `npm audit` не сообщил известных уязвимостей на момент проверки.

Регрессионные тесты покрывают исходные воспроизведения, диапазоны/patch/undo, миграцию/конкурентную запись, карту/кэш, grouping/context, TypeScript tools и запрет сети/внешнего чтения процесса. Нативный Electron smoke проверяет draft connection, карту, reload во время approval, запись/undo, worker и компилятор.

Реальная `qwen2.5:1.5b` успешно отвечает на connection probe, но не исправила обе задачи coding baseline: [отчёт](./local-evaluation.json). Повтор после упрощения аргументов patch тоже дал 0/2: [подробные вызовы и ответы](./local-evaluation-v02.json). Это ограничение текущей пары модель/harness; smoke проверяет интеграцию, а не способность решать задачи. Второй установленный вариант также не исправил эти две задачи: [llama baseline](./local-evaluation-llama.json).

Реальное MLX обучение не запускалось: необходимого runtime/набора весов нет. Тест launcher использует синтетический исполняемый файл. CI пока проверен только локальными эквивалентами команд; публичного подписанного релиза нет.
