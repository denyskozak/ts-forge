# Критические уточнения во время задачи

Forge может остановить агентский цикл и задать один вопрос с 2–4 вариантами ответа. Это отдельный инструмент `ask_user_question`, а не обычный текстовый ответ модели.

## Когда агент спрашивает

Перед выбором действий на каждом шаге модель проверяет, есть ли неизвестное решение, которое существенно меняет архитектуру, поведение, риск потери данных или объём задачи. Вопрос нужен только тогда, когда ответ нельзя получить из проекта через инструменты чтения.

Агент не должен спрашивать о мелких предпочтениях, безопасных обратимых решениях и фактах, которые можно найти в коде.

## Как продолжается выполнение

1. Модель вызывает `ask_user_question` отдельно от зависимых действий.
2. Forge сохраняет вопрос в активном запуске и показывает варианты над полем ввода.
3. Агент остаётся в состоянии `waiting`, пока пользователь не выберет вариант или не остановит запуск.
4. Выбранные название и описание возвращаются модели как результат инструмента.
5. Следующий шаг строится уже с учётом ответа.

Если модель поместила вопрос и другие инструменты в один ответ, Forge пропускает остальные вызовы этого шага. Это не позволяет применить изменение до получения критического решения.

Перезагрузка интерфейса восстанавливает активный вопрос из локального состояния. Полный перезапуск Electron завершает запуск как прерванный, потому что ожидающий процесс модели уже не существует.
